2026-10-16 当前交接版。背景主题、多光源和列表交互、IndexedDB 草稿、设计包已实现；停止今日开发，等待另一台 Windows 真机导入验收。不进入第三阶段文字/按钮/布局编辑。

## 启动与检查

使用 Node.js 24 LTS，无需安装依赖：

```powershell
node --test tools/visual-lab/*.test.js
node tools/visual-lab/check-production.js
node tools/visual-lab/server.js
```

成功标志：25 项通过，隔离检查 PASS，终端显示 http://127.0.0.1:4185/__visual-lab/ 。有 npm 时也可使用 npm run lab:check / npm run lab。不要用原站 npm start 或 Netlify 命令启动工具。

服务仅绑定 127.0.0.1，只读 data/portfolio.json 和静态文件；拒绝写请求、管理/云端路径、非法 Host/Origin 和路径越界。仅专用服务对预览首页注入桥接，不修改 public/、正式 server.js 或部署配置。

## 背景与光源操作

1. 选择中文/英文、桌面/移动、预览宽度；所有操作作用于真实首页 Banner，保留动画。
2. 切换深色/亮色/自定义主题。图片、渐变、光源、遮罩可独立开关；图片支持替换、缩放、位置、滤镜。深色默认与原站一致；亮色不会继承黑色遮罩。
3. 推荐文字/按钮配色需主动点击；亮底照片墙/浮卡适配可关闭。背景切换/恢复不自动覆盖主动应用的配色。
4. 展开“多光源 · 列表与调节”，顶部新增入口可选预设或自由颜色，最多五源。原环境光单独设置，不占名额。
5. 单击列表行或名称选中，下方属性和画布控制点同步。双击名称行内重命名；Enter 确认，Esc 取消，失焦确认，空名恢复旧名。新增/复制自动避开已有名称。
6. 勾选控制当前设备显隐，上下箭头排序（列表顶部为前景）；复制/删除位于属性标题旁。属性区单独滚动，切换其他光源回顶部。
7. 通用 → 桌面 → 移动依次覆盖。名称/名单/顺序共用，参数独立；桌面也是未覆盖移动参数的继承来源。颜色、X/Y、强度为常用；宽高、旋转、柔化、模糊、混合在高级区。
8. 拖动中心点定位，始终写入当前设备；方向键微调，Shift 加速，Esc 退出。正常预览无轮廓；控制点不是发布内容。暂不支持画布缩放/旋转，使用面板。
9. 单范围恢复回到默认/继承；全部光源恢复回到原橙色主光源。背景恢复不清空多光源。切换设备/语言/主题不删除已有光源或自动改其混合。

数据结构为 design.lighting={version,order,sources}，每源 name/defaults/base/desktop/mobile。渲染坐标基于 iframe 内 Banner 实际矩形；手势 ID、pointer capture 和修订回执保护最终落点。

## 保存与迁移

展开“草稿与设计包”。选新草稿、命名、保存；选择已有草稿后保存会更新该条。刷新后主动打开并确认。IndexedDB 保存真实图片，最多十份，按当前浏览器和 origin 隔离；手动保存，不自动云同步。

导出 .feiroo.zip，将文件带到另一台电脑同版本工具导入；先校验并展示摘要，再确认替换。导入后可另存本机草稿。详细结构、安全限制和测试见 [STORAGE.md](STORAGE.md)。

图片未保存时刷新会丢失；保存草稿/包后可恢复。支持静态 JPEG/PNG/WebP/AVIF，最大单边 16384、3200万像素。包限制单文件 20 MiB、ZIP/解压各 100 MiB、100 条目，清单 2 MiB。ZIP STORE、不支持手工压缩/加密/ZIP64 或未知版本字段，不执行包内容，不向源码解压。

设计包带齐引用的替换图片；原站内置图片/字体/种子仍由同基准仓库提供。它不是独立网站安装包。schema.baseCommit 固定为原站基准 2e8d26d…，不要改成工具提交 HEAD。
